# Trip Buddy

An Android app built with Android Studio to help you plan your perfect trip.

## Features

- **Budget Planning** - Track and manage your trip expenses
- **Memory Saving** - Save and organize your favorite trip memories
- **Custom Themes** - Personalize the app with custom themes

## About

Trip Buddy is your all-in-one travel companion for organizing trips, managing budgets, and preserving your best travel moments.
